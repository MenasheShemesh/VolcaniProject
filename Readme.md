##ממשק לשליחת SMS##

#הנחות יסוד#
1. יש לדמות פניה לספק SMS חיצוני, מכיוון שלא קיבלתי נתיב ודרך פניה.
2. המזהה הייחודי של כל עובד מורכב מ-שם(פרטי ומשפחה), וכתובת(עיר, רחוב, מספר בית).

#מסד נתונים#
יצרתי סכמה בתבנית סכמת כוכב, כאשר טבלת ההודעות היא טבלת העובדות, 
ויש לה טבלת מימד אחת - שהיא טבלת העובדים, כאשר יש מפתח זר בטבלת ההודעות שמקשר ביניהם.
כאשר מכניסים הודעה חדשה לטבלה, בודקים האם העובד שמופיעה בהודעה, כבר קיים בטבלת העובדים, 
אם כן משתמשים במזהה שלו, אם לא יוצרים רשומה חדשה של עובד בעלת מזהה חדש(ללא קשר למספר העובד שלא נגיש אלי).
הגישה בפועל לעדכון/שליפה מהטבלאות מתבצעת באמצעות Stored Procedures.

#צד שרת#
בחרתי לבנות צד שרת ב- Net WebApi., באמצעות שימוש בספריות ADO.Net(בכדי לאפשר גישה נוחה לפרוצדרות במסד הנתונים).
מבחינת מודלים, בחרתי לחלק את המודל המרכזי שהוא Message למספר תת-מודלים שהוא מכיל בתוכו (Worker, Address, Phone).
בנוסף הארכיטקטורה של השירות מורכבת ממספר שכבות(API,BL,DAL,Infra) שכל אחת מהן מהווה פרוייקט נפרד, והן מקושרות ביניהן.
בדיקת הנתונים מתבצעת באמצעות הספריה של Model Validation בממשק ה- WebApi.

#מה בחרתי שלא לעשות#
בחרתי שלא להשתמש ב-EntityFramework למרות שיכולתי, ויש לי גם את הניסיון בכך, משום שרציתי להשתמש גם ב-SQL וב- Stored Procedures.
בנוסף, בחרתי שלא להשתמש בכלי AI(למרות שיש לי גם ניסיון בכך) בכדי לבחון ולהראות את היכולות האמיתיות שלי תוך כדי מבחן אמיתי.

#מה הייתי מוסיף אילו נשאר לי זמן נוסף#
מוסיף עוד דברים לצד הלקוח שפיתחתי באנגולר.
